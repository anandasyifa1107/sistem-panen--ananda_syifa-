# Sistem Panen Digital
Repositori ini berisi proyek program Python sederhana untuk menghitung total hasil panen beserta fitur diskon yang dikembangkan sebagai bagian dari praktikum Algoritma dan Pemrograman Komputer.

## Cara Menjalankan Program
1. Clone repositori ini ke komputer atau Google Colab:
   `git clone https://github.com/anandasyifa1107/sistem-panen-anandasyifa.git`
2. Masuk ke direktori proyek:
   `cd sistem-panen-anandasyifa`
3. Jalankan berkas Python:
   `python main.py`
